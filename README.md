# EuroPrêt Expert - Plateforme de Crédit Européen

Application web interactive de simulation et de gestion de prêt respectant les directives européennes (DCC, MCD, SECCI/FIPEN).

## Fonctionnalités
- Simulateur de prêt interactif (TAEG, mensualités, tableau d'amortissement, export PDF).
- Module de vérification du taux d'endettement (normes HCSF 35%).
- Authentification client (Inscription / Connexion).
- Tableau de bord client ("Mon Espace") pour suivre les demandes et soldes.
- Interface d'administration ("Espace Admin") pour valider les demandes et créditer les soldes.
- Guide réglementaire européen et comparatif des taux par pays.

## Déploiement sur Render
1. Déposez ce dépôt sur GitHub.
2. Connectez Render à votre dépôt GitHub.
3. Créez un **Web Service** ou **Static Site**.
4. Render utilisera la commande `npm start` pour démarrer le serveur.
